# Stock Price Predictor

## 📌 Project Overview
This project predicts stock prices using historical stock market data and Linear Regression.

## 🎯 Objective
The main objective is to analyze historical stock data and predict the next stock price based on previous prices.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 📊 Dataset
The project uses historical Apple (AAPL) stock data containing:
- Date
- Open Price
- High Price
- Low Price
- Close Price
- Volume

## 🔄 Project Workflow
1. Collected historical stock data
2. Loaded the dataset using Pandas
3. Cleaned and processed the data
4. Selected relevant features
5. Trained a Linear Regression model
6. Predicted stock prices
7. Saved the processed dataset

## 📈 Result
The model successfully generates stock price predictions based on historical data.
